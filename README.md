# business-automation-tools

Ce projet open-source regroupe des outils pour aider les entrepreneurs indépendants (MLM, créateurs de contenu, traders, freelances) à automatiser leur activité, suivre leurs résultats et créer des tableaux de bord éducatifs.

Les objectifs principaux :
- Scripts Python pour l’automatisation (reporting, suivi de performances, gestion de données).
- Dashboards Streamlit pour visualiser les résultats (trading, ventes, contenu).
- Modèles de workflows pour le marketing digital et les équipes de vente directe.
- Ressources pédagogiques en français et en espagnol pour rendre ces outils accessibles à des non-développeurs.

Ce dépôt servira de base pour publier et documenter ces outils afin que d’autres puissent les utiliser, les forker et les améliorer.

## About this project (English)

This open-source project gathers tools to help independent entrepreneurs (MLM distributors, content creators, traders, freelancers) automate their business, track results, and build educational dashboards.

Main goals:
- Python scripts for automation (reporting, performance tracking, data management).
- Streamlit dashboards to visualize results (trading, sales, content).
- Workflow templates for digital marketing and direct sales teams.
- Educational resources in French and Spanish so non-developers can use and adapt these tools.

This repository will be the main place to publish and document these tools so others can use, fork, and improve them.
